# Data Cleaning and Data Quality Analysis

## Internship
Oasis Infobyte – AICTE OIB-SIP October P1

## Track
Data Analytics

## Task
Level 1 – Task 3: Data Cleaning

## Project Description
This project focuses on checking and improving the quality of a retail sales dataset using Python.

## Dataset
Retail Sales Dataset – Kaggle

## Tools and Libraries
- Python
- Google Colab
- Pandas
- NumPy

## Work Performed
- Loaded and explored the retail sales dataset
- Checked missing values
- Identified and removed duplicate records
- Examined unique values in categorical columns
- Identified outliers using the IQR method
- Converted the Date column into datetime format
- Generated a cleaned dataset
- Saved the cleaned dataset as a CSV file

## Output
The cleaned dataset is saved as `cleaned_retail_sales_dataset.csv`.

## Conclusion
The dataset was examined for data quality issues. Duplicate records were handled, the date format was standardized, and outliers were examined using the IQR method. The cleaned dataset is ready for further analysis.
