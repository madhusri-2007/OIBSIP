# EDA on Retail Sales Data

## Internship
Oasis Infobyte – AICTE OIB-SIP October P1

## Track
Data Analytics

## Task
Level 1 – Task 1: Exploratory Data Analysis (EDA)

## Project Description
This project performs Exploratory Data Analysis on a retail sales dataset to understand sales trends, customer demographics, and product category performance.

## Dataset
Retail Sales Dataset – Kaggle

## Tools and Libraries
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

## Analysis Performed
- Dataset overview and inspection
- Monthly sales trend analysis
- Age distribution analysis
- Gender distribution analysis
- Product category sales analysis
- Top 10 transactions based on total amount
- Correlation analysis
- Sales analysis by gender

## Key Findings
The analysis helps understand monthly sales patterns, customer demographics, and category-wise sales performance.

## Conclusion
Exploratory Data Analysis provides useful insights into retail sales data and helps identify patterns that can support better business decisions.**
