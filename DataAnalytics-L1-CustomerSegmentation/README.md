# Customer Segmentation Analysis

## Internship
Oasis Infobyte – AICTE OIB-SIP October P1

## Track
Data Analytics

## Task
Level 1 – Task 2: Customer Segmentation Analysis

## Project Description
This project uses customer purchasing behaviour to group customers into different segments using the K-Means clustering algorithm.

## Dataset
Retail Sales Dataset – Kaggle

## Tools and Libraries
- Python
- Google Colab
- Pandas
- Matplotlib
- Scikit-learn

## Work Performed
- Loaded and explored the retail sales dataset
- Calculated customer spending and purchase frequency
- Selected features for customer segmentation
- Applied feature scaling using StandardScaler
- Used the Elbow Method to study the number of clusters
- Applied K-Means clustering
- Visualized customer segments
- Analyzed cluster profiles

## Conclusion
Customer segmentation helps identify groups of customers with similar purchasing behaviour. These insights can support targeted marketing and better business decisions.
